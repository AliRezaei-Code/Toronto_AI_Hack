# Rententio Landing Page Spec

## UX goal (1 sentence)
Drive the user to start or sign in within seconds by making the value obvious and the action effortless.

## Rententio Landing Page Rules
1) One job only: get the user to sign in or start.
2) Hero answers three questions: what is this, why it matters, what to do next.
3) CTA dominance: primary CTA is visually strongest; secondary is de‑emphasized.
4) Creativity is environmental: visuals frame the content, never interrupt it.
5) No deep feature explanation in hero; details belong below the fold or in‑app.
6) Landing ≠ app UI: expressive is fine, but do not invent new interaction patterns.

## Copy placeholders
- One‑sentence positioning: “Rententio helps creators turn raw clips into retention‑optimized videos automatically.”
- Hero headline (6–12 words): “AI video editing that keeps viewers watching.”
- Hero subtext (1 sentence): “Upload clips and get a retention‑optimized cut in minutes.”
- Primary CTA: “Get started”
- Secondary CTA: “Sign in”

## Component list
- Top nav (logo + minimal links)
- Hero headline (H1)
- Hero subtext (1 sentence)
- Primary CTA button
- Secondary CTA link/button (quieter)
- Supporting visual (abstract / gradient / illustration)
- Optional below‑fold section(s): 1–2 short blocks max
  - Social proof (logos) OR
  - How it works (3 steps)

## Layout & hierarchy
- Hero content visible above the fold on desktop and mobile.
- CTA placed adjacent to headline/subtext, not separated by visuals.
- Visual element sits beside or behind hero text; never between text and CTA.
- No feature lists or bullets in the hero.

## Tone
Confident, calm, minimal hype. No “AI magic” language.

## CTA decision
Primary CTA: “Get started”.
Secondary CTA: “Sign in”.
